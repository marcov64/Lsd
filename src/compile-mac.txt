To configure for embedded TclTk in macOS 
(see http://wiki.tcl.tk/12987 and https://wiki.tcl.tk/12945)


AUTOMATED COMPILATION

The script compile-tcltk-mac.sh perform the steps below automatically. Use the manual instructions only if it fails to create the desired app bundles.

To run the script (all arguments are likely required):

~/LSD/src/compile-tcltk-mac.sh arm64 8.6.18 ~/LSD

Adjust, as necessary, the architecture (arm64/x86_64), the Tcl/Tk version (8.6.X), and the LSD installation folder.


MANUAL INSTRUCTIONS

Make sure you have the latest version of CLANG compiler installed:

sudo rm -rf /Library/Developer/CommandLineTools
xcode-select --install

Download TCL and TK zip files (https://www.tcl.tk/software/tcltk/download.html).

Extract tclX.X.X and tkX.X.X subdirectories under a common directory (i.e., /Users/Marcelo/TclTk). Remove old versions before compilation.

To build, use the scripts in both tclX.X.X/macosx and tkX.X.X/macosx, in this order:

# workaround for bugged macOS 27 compilation
export SDKROOT=$(xcrun --sdk macosx26.5 --show-sdk-path)/

ver="8.6.X"
tcltk="/Users/Marcelo/TclTk"
lsd="/Users/Marcelo/LSD"

# intel binaries
dest="${tcltk}/x86_64"
export CFLAGS="-arch x86_64 -mmacosx-version-min=11.0"

# arm binaries
dest="${tcltk}/arm64"
export CFLAGS="-arch arm64 -mmacosx-version-min=11.0"

cd ${dest}

make -C tcl${ver}/macosx clean
make -C tk${ver}/macosx clean

make -C tcl${ver}/macosx deploy
make -C tk${ver}/macosx deploy

make -C tcl${ver}/macosx install-embedded INSTALL_ROOT=${dest}
make -C tk${ver}/macosx install-embedded INSTALL_ROOT=${dest}

Please adapt ver, tcltk and lsd to the version used and the path of Tcl/Tk sources and LSD.

In LMM.app/Contents, LSD.app/Contents, and installer/LSD Installer.app/Contents remove the Frameworks subfolder.

Copy the Frameworks subfolder from TclTk/Applications/Utilities/Wish.app/Contents, into LMM.app/Contents, LSD.app/Contents, and installer/LSD Installer.app/Contents.

Copy only to LSD.app/Contents/Frameworks the MISSING Headers, PrivateHeaders, libtclstub8.6.a and libtkstub8.6.a items from build/tcl/Tcl.Framework[/Versions/8.6] and build/tk/Tk.Framework[/Versions/8.6], being careful to not overwrite the existing files. Copy files and the respective link files. Copy link files ONLY after copying real files/folders.

Copy only to installer/LSD Installer.app/Contents/MacOS the Wish file from TclTk/Applications/Utilities/Wish.app/Contents/MacOS.

Copy only to installer/LSD Installer.app/Contents/Resources the Wish.sdef and Credits.html files from TclTk/Applications/Utilities/Wish.app/Contents/Resources.
