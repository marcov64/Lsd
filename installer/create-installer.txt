To all:
1. Update LSD_VER_NUM and LSD_VER_TAG in create-installer-xxxx.yyy

To create Windows .exe installer
1. Get 7-Zip LZMA SDK at https://www.7-zip.org (ex. lzma1900.7z)
2. Copy 7zSD.sfx to gnu\installer folder in LSD installation
3. Open 7zSD.sfx in Resource Hacker (http://www.angusj.com/resourcehacker)
4. Menu Action > Add from Blank Script
5. Import manifest from 7zSD-manifest.xml
6. Menu Action > Compile Script
7. Menu File > Save
8. Modify config-installer-windows.txt extraction configuration if needed
9. Add files/patterns to exclude to exclude-installer-windows.txt
10. Run create-installer-windows.bat to create installer

To create macOS DMG installer
1. Update LSD_VER_NUM and LSD_VER_TAG in run-installer-mac.sh
2. Add files/patterns to exclude to exclude-installer-mac.txt
3. Run create-installer-mac.sh to create the installer

To test macOS installer
1. Remove previous installer authorizations: tccutil reset All com.marcov64.lsdi
2. Remove previous LSD authorizations: tccutil reset All com.marcov64.lsd
3. Remove previous LMM authorizations: tccutil reset All com.marcov64.lmm
4. Remove previous terminal authorizations: tccutil reset AppleEvents com.apple.terminal
5. Remove Xcode command line utilities: sudo rm -rf /Library/Developer/CommandLineTools
6. Remove Homebrew and its packages: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/uninstall.sh)"
7. Remove Homebrew environment variables: rm ~/.zprofile ~/.zshrc
